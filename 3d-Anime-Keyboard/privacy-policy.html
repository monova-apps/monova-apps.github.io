2. Keyboard Input and Sensitive Text

Input-method functionality

An enabled Android keyboard processes input to enter or edit text in the application you are using. Android's input connection can also make surrounding text and editing context available to the keyboard, subject to the receiving app and platform behaviour.

This can involve information beyond individual key presses, such as a selected word or text around the cursor. An input connection is not the same as unrestricted access to all historical conversations.

Text entered into another application is received by that application. Its subsequent handling is governed by that application's practices. This is distinct from a keyboard separately storing text or transmitting it to a remote service.

Passwords and other sensitive information

Typed content can include passwords, payment details, authentication codes, private messages, health information, and other sensitive material. Masking characters in a text field is not proof that no keyboard processing occurs.

Android provides password-field indicators and signals requesting that a keyboard avoid personalised learning. Those mechanisms require appropriate handling by the keyboard; they are not an independent verification of this Application's behaviour.

Typing suggestions and learned words

Where prediction, autocorrection, or personalised suggestions are implemented, those functions may use language choices, words you add, or information learned from input. The actual information used and whether processing is local or remote must be specified for this Application.

Disabling future learning is different from deleting information already learned. A personal dictionary can contain names or other private information, even when it is not labelled as a message history.

Clipboard functionality

Pasting text into the active field is different from maintaining a separate clipboard history. Clipboard content can include private messages, addresses, passwords, or verification codes.

Any clipboard feature must explain when content is read, whether it is retained, how pinned items are handled, and how users remove saved copies. Clearing the system clipboard does not necessarily erase a separate history created by an application.

Switching keyboards is not the same as deleting stored app information, uninstalling the Application, or withdrawing advertising consent. Merely closing its settings screen is not the same as disabling an active keyboard.
