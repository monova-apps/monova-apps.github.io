3. Permissions, Overlays, and User Controls

Display over other apps

Where an overlay feature is implemented, the Application may request Android's “Display over other apps” special access to show the selected visual effect above another app. Android requires the relevant user authorisation for this access on supported versions.

In the configuration described here, overlay access is used only to display the effect and handle interaction with its controls. It is not used to record the screen, collect credentials, read other apps' content, or monitor activity in other apps.

You can revoke available overlay access through Android's special app-access settings. Removing that access prevents the overlay feature from operating; it does not necessarily remove saved app preferences.

Notifications and ongoing effects

Where an ongoing-effect feature uses a notification, the notification is for app status or controls. Showing the Application's own notifications is different from receiving access to notifications belonging to other apps.

Use available stop controls to end an effect. When an effect runs outside the main app screen, leaving that screen may not itself stop the effect. Android's app-info controls can also be used to force-stop the Application.

This configuration does not use camera or microphone recording, precise location, contacts, messages, call history, screen capture, or an accessibility service. It does not require broad photo-library access to render the included visual effects.
