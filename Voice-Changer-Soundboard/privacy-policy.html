4. Permissions and Recording Controls

Microphone access

On Android, a feature that records microphone audio requires the relevant recording permission. Declining or withdrawing microphone access prevents microphone functions that depend on that permission. Playing an existing sound is different from recording.

Stopping recording, discarding a recording, and deleting a saved file are separate actions. Closing the main screen must not be treated as proof that every recording or processing task has stopped.

Imported files and other access

Opening a selected audio file is different from browsing an entire media library. A selected file may also come from a cloud-backed document provider, whose retrieval of that file is separate from any upload performed by the Application.

Complete the permission and control disclosure: [List actual permissions and special access, with a purpose for each.
